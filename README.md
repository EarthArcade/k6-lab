# k6-lab

ITDS362 Software Quality Assurance and Testing — Lab: Performance Testing with Grafana K6.

Scripts for Part 0 (K6 basics) and Part A (smoke, average-load, stress, spike and soak tests) against
[QuickPizza](https://quickpizza.grafana.com). Results and the Part B reflection are in [RESULTS.md](RESULTS.md),
and the HTML reports of Steps A2 to A5 are in [reports/](reports/).

Run any script with `k6 run <script>.js` (tested with k6 v2.2.0).
